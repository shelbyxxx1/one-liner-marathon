A dependency-free Python program that writes one fixed, original joke to
`/output/entry.txt` as UTF-8, without a trailing newline, and prints its character
count. Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory.

## Run it

```sh
python3 main.py
```

`tournament.json` records the local editorial scores and pairwise comparisons for
14 original candidates and the two supplied seeds. The suitcase won nine
consecutive comparisons; its wording was tightened after the first program run.
These are self-assessments, not official make.fun results. The program never reads
the tournament file and uses only the Python standard library.
